WhatsApp Invoice Alerts

Use international format without + or spaces.
How it works:
When an invoice is saved, Invoice Studio sends the invoice details to your secure backend. The backend sends the WhatsApp message through the WhatsApp Business Cloud API. Your Meta access token stays on the server and is never stored in this HTML file.
WhatsApp Business App connection is managed through Meta Embedded Signup.

No log yet.

Recommended Meta Setup

  1. Create/verify your Meta Business portfolio and WhatsApp Business Account.
  2. Add/register the WhatsApp Business phone number you want to use for sending.
  3. Create an approved WhatsApp utility template named invoice_created.
  4. Put your Meta access token and WhatsApp Phone Number ID in the backend server, not in this HTML.
  5. Run the backend and set its public URL above.

FBI MoMo Link

Install this on the Android phone that receives your MTN MoMo payments. It sends only the “Payment received” messages to Invoice Studio.

Download the app

Android only · about 50 KB-2 MB

Install and link
  1. Open the downloaded file. If Android asks, allow your browser to install unknown apps.
  2. Open FBI MoMo Link and tap Allow SMS access.
    If Android blocks it: Settings → Apps → FBI MoMo Link → ⋮ → Allow restricted settings, then Permissions → SMS → Allow.
  3. On a computer, open Invoice Studio → MoMo payments → Link phone, and type the 6-digit code into the app.
  4. Set the app's battery use to Unrestricted so the phone doesn't pause it.

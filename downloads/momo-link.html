Install and link
  1. Tap Download the app and open the file. If Android asks, allow your browser to install unknown apps.
  2. Open FBI MoMo Link and tap Allow SMS access.
    If Android blocks it: Settings → Apps → FBI MoMo Link → ⋮ → Allow restricted settings, then Permissions → SMS → Allow.
  3. On a computer, open Invoice Studio → MoMo payments → Link phone and scan the QR code with this phone's camera.
  4. Set the app's battery use to Unrestricted so the phone doesn't pause it.
